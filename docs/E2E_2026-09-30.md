## Bugs found and fixed through this test

1. **Wrong error for an already-registered email.** The error mapping (ported from SMSDC) turned every HTTP 409 into "that time was just taken" and sent the visitor back to pick a new time. `AUTH_EMAIL_ALREADY_EXISTS` now has its own message and returns to the details step; unknown 409 codes show a generic message. Unit-tested.
2. Phone hint promised an SMS code in WhatsApp/enquiry modes — now mode-aware.
3. The booking result showed core's placeholder surname ("Dr. Sindhu MDS") — now uses the website's display name.
4. Tenant file: core refuses treatments on STARTER (402 `GALLERY_NOT_ENTITLED`, Pro+ only) — the generator no longer imports them on Starter.

## Core observations (for the ClinicFlow team)

- The 402 message says "upgrade to Starter or above", but the gate is Pro+.
- The importer leaves new clinics PENDING (public endpoints 404 until a super-admin sets ACTIVE).
- `D:\ClinicFlow\CLAUDE.md` documents a seeded super-admin login that differs from the one migration V9 actually seeds (credentials deliberately not repeated here). If staging was migrated from the same seeds, that account should have a non-default password.
