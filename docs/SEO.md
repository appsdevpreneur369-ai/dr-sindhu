# SEO

## Environment

| Variable | Production | Staging / local |
| --- | --- | --- |
| `NEXT_PUBLIC_SITE_ENV` | `production` | `staging` / unset |
| `NEXT_PUBLIC_SITE_URL` | `https://<clinic domain>` (canonical, sitemap, OG, JSON-LD) | staging URL |
| `NEXT_PUBLIC_NOINDEX` | unset | optional `true` |
| `NEXT_PUBLIC_SHOW_PLACEHOLDER_BADGES` | `false` | `true` |

Anything other than `production` is **noindex**: `<meta name="robots" content="noindex,nofollow">`, `X-Robots-Tag: noindex, nofollow` header and `robots.txt` → `Disallow: /`.

## What every page has

- Unique `<title>` (≤ 60 chars; " | Dr. Sindhu Dental, Tadepalli" appended when it fits) and meta description (from `content/pages.json`, category `seo`, article front-matter).
- Exactly one `<h1>`; breadcrumbs on inner pages.
- Canonical URL from `NEXT_PUBLIC_SITE_URL`; Open Graph + Twitter card with the 1200×630 share image (`public/images/og.png`, regenerated by `npm run brand`).
- `/sitemap.xml` with `<image:image>` entries; `/robots.txt`; `manifest.webmanifest`; favicon + app icons.

## Structured data (JSON-LD)

| Where | Types |
| --- | --- |
| Every page | `Dentist` (LocalBusiness + MedicalOrganization): name, address, `openingHoursSpecification` (two sessions, Mon–Sat), `areaServed`, logo, image, `medicalSpecialty`, `founder`. **`telephone` only while the phone is approved; `email`, `postalCode`, `geo`, `hasMap`, `sameAs` are omitted while they are placeholders/empty.** No `priceRange`, no ratings. |
| Doctors list + each doctor | `IndividualPhysician` ×3 (schema.org's Physician subtype for one doctor), `practicesAt` → the clinic |
| Inner pages | `BreadcrumbList` |
| Treatment pages | `MedicalWebPage` about `MedicalProcedure`s + `FAQPage` |
| Articles | `MedicalWebPage` + `Article` with `ImageObject` |
| Gallery | `ImageGallery` of `ImageObject`s |
| FAQs | `FAQPage` |

Validation: `node scripts/qa/seo-audit.mjs <base> <schemaorg-current-https.jsonld> out.json` checks every sitemap URL (titles, descriptions, H1, canonical, robots, OG/Twitter, alts, sitemap images) and validates the JSON-LD **locally** against the official schema.org vocabulary (`https://schema.org/version/latest/schemaorg-current-https.jsonld`) — no page content leaves the machine. Result 30 Sep 2026: 30 pages, **0 JSON-LD errors, 0 issues** (`docs/seo-reports/2026-09-30/seo-audit.json`). After go-live also run Google's Rich Results Test on the live URLs.

## Local SEO notes

- "Ashramam Road" and "Tadepalli" appear naturally in the H1-adjacent eyebrow, titles, descriptions and footer; nearby places (Undavalli, Mangalagiri, Vijayawada) only in `areaServed` and the Visit section. No keyword lists.
- All copy is original — nothing is reused from the SMSDC site, which is also in Tadepalli.
- Google Business Profile: see `GBP-Checklist.txt`. Use the **same name, address and phone** on GBP and the site (NAP consistency). Add the GBP URL to `social.json`/`sameAs` once verified.
