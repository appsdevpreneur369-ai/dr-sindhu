# Dr. Sindhu Dental Clinic — public website

Public website for **Dr. Sindhu Dental Clinic**, Ashramam Road, Tadepalli (project code **DRSDC**), a ClinicFlow247 STARTER clinic.

Next.js 14 (App Router) · TypeScript · Tailwind · zod-validated content · vitest. Booking connects to ClinicFlow247 (with automatic fallback to an enquiry or WhatsApp).

## Quick start

```bash
npm install
npm run dev            # http://localhost:3000
npm run check          # lint + typecheck + unit tests + WCAG contrast + production build
```

Build-time settings (`.env.production.local`, or Docker build args):

| Variable | Meaning |
| --- | --- |
| `NEXT_PUBLIC_SITE_ENV` | `production` = indexable; anything else = noindex |
| `NEXT_PUBLIC_SITE_URL` | Canonical base URL (sitemap, OG, JSON-LD) |
| `NEXT_PUBLIC_SHOW_PLACEHOLDER_BADGES` | `true` shows "Draft" badges on unconfirmed content (staging) |
| `NEXT_PUBLIC_CLINICFLOW_API_URL`, `…_CLINIC_SLUG`, `…_CLINIC_ID` | ClinicFlow247 booking API (empty → WhatsApp booking) |
| `NEXT_PUBLIC_BOOKING_OTP_HINT` | Staging only: test OTP hint |

## Where things are

| Path | What |
| --- | --- |
| `content/` | **All** site content (clinic details, doctors, treatments, pages, articles, legal drafts). Every record is `approved` or `placeholder`. |
| `src/lib/content/` | zod schemas + loader — a bad content edit fails the build with the file and field named |
| `src/lib/booking/` | Booking service, ClinicFlow API client, fallback rules (clinicflow → enquiry → whatsapp) |
| `src/app/`, `src/components/` | Pages and UI |
| `scripts/` | Brand assets, image variants, contrast check, tenant file generator, QA tools |
| `tenant/dr-sindhu.json` | ClinicFlow247 onboarding file (generated by `npm run tenant`) |
| `docs/` | EDITING (who edits what), BOOKING, SEO, UPGRADE_TO_ENTERPRISE, test reports, screenshots |

Start with **`docs/EDITING.md`** to change content, and **`CLAUDE.md`** for project rules and deployment.

## Deployment

Manual, like the other ClinicFlow247 sites: build the Docker image locally, push to Artifact Registry, `gcloud run deploy`. Commands and history: `CLAUDE.md → Deployments`.
